# Advanced AI & ML – Telecom Data Analytics

A day-wise learning and practical documentation repository for the **Advanced AI & ML – Telecom Data Analytics** 10-day programme.

**Duration:** 10 days × 4 hours/day = 40 contact hours

## Learning philosophy

The programme follows:

**Domain → Data → Models → Intelligence → Delivery**

The first three days establish the telecom domain and data foundations before machine learning is introduced.

## Learning goal

The objective is not merely to run commands. I am building an understanding of how:

```text
Telecom Network
      ↓
Raw Operational Data
      ↓
Data Cleaning / ETL
      ↓
Governed Analytical Dataset
      ↓
Machine Learning
      ↓
BI / Deployment
      ↓
Business Decision
```
